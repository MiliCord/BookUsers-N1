# BookUsers

Aplicación de escritorio en Java Swing para registrar usuarios, listarlos,
ver su detalle y generar un PDF con su información.

## Cómo ejecutar

1. Clonar el repositorio y abrirlo en IntelliJ IDEA (Java 21).
2. Verificar que la carpeta `lib/` contiene `generate-pdf-java.jar`
   y que está registrada como librería del proyecto
   (clic derecho sobre el `.jar` → Add as Library).
3. Ejecutar el método `main` de la clase `FormMenu`.
